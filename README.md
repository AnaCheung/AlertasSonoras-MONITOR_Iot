# AlertasSonoras-MONITOR_Iot

### Descripción del proyecto

**AlertasSonoras-MONITOR_Iot** es un sistema de monitoreo desarrollado en Python que permite supervisar diferentes recursos del equipo en tiempo real y generar **alertas sonoras** cuando se detectan eventos importantes.

El proyecto busca implementar alertas en el nodo de telemetría para identificar situaciones como:

* 🖥️ Uso elevado de CPU.
* 💾 Uso elevado de memoria RAM.
* 🌐 Tráfico de red.
* 🔌 Conexión de red.


Las alertas funcionan mediante una programación orientada a eventos y un sistema de reproducción de sonidos que permite mantener activo el monitoreo del dashboard sin bloquear su funcionamiento.


## Tecnologías utilizadas

| Tecnología                           | Uso                                                |
| ------------------------------------ | -------------------------------------------------- |
| **Python**                           | Lenguaje principal del proyecto                    |
| **Tkinter**                          | Desarrollo de la interfaz gráfica                  |
| **psutil**                           | Obtención de información y métricas del sistema    |
| **Sistema de reproducción de audio** | Generación de alertas sonoras                      |
| **Git / GitHub**                     | Control de versiones y almacenamiento del proyecto |
